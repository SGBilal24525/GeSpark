# **App Name**: GeSpark Toolkit

## Core Features:

- Sticky Header: Implement a responsive, sticky header with logo, menu, and CTA button.
- Hero Section: Design a hero section with text on the left, animated floating tool cards on the right, a gradient background, and two CTAs.
- Tools Section with Tabs: Create a main section for tools, separated by tabs ('Calculators', 'Converters').
- Dynamic Firestore Fetching: Fetch tool data dynamically from a Firestore 'tools' collection.
- Responsive Grid Layout: Display tools in a responsive grid (4 columns desktop, 2 tablet, 1 mobile) with tool cards (icon, title, description, button). An AI powered tool can use other AI tools if useful.
- About Section: Create a two-column about section (text + illustration).
- SEO Meta Tags: Auto-generate SEO meta tags (title: 'GeSpark — Smart Online Tools', meta description).

## Style Guidelines:

- Primary color: HSL (210, 65%, 50%) - A vibrant blue to signify intelligence and reliability. Hex code: #3399FF
- Background color: HSL (210, 20%, 95%) - Very light blue for a clean, modern feel. Hex code: #F0F8FF
- Accent color: HSL (240, 50%, 50%) - A deep violet to complement the primary blue, indicating creativity. Hex code: #6666CC
- Headline font: 'Space Grotesk', sans-serif. Body font: 'Inter', sans-serif. Combination of a techy font for headlines, and a neutral font for body text.
- Use a consistent style of flat, minimalist icons to represent each tool.
- Employ a clean, modern layout with generous spacing and a clear visual hierarchy.
- Implement subtle fade-in animations using Framer Motion for smooth transitions and engagement.
